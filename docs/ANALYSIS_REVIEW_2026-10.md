**パラメーター(2026)**: INF版 = SLS-BndTE/2=12,400 / Bnd6=12,400 / Bnd7=15,500 / Bnd8=17,600 / Bnd9=20,000 / Bnd10=22,900(円/時)。**TPS2026v1(最新・CPS作成ツールが使用)は Band6=13,100 / Band7=16,400 / Band8=18,600 / Band9=21,800 / Band10=25,200 / Executive=25,200**(2026-10の追記。§8参照)。

**Risk Level→Contingency**: 1=4% / 2=5% / 3=7% / 4=9% / 5=14% / 6=18% / 7=22% / 8=26% / 9=30%。

**数式の核**: `Contingency額 = コスト合計×Cont率` / `POC = コスト合計(Cont含) / (1-承認GP)` / `Revenue = Σ月別POC` / `Cont率 = VLOOKUP(RiskLevel, ContRate)`。

**補足(単価の差異)**: CPSパラメーターの Bnd8 は INF版 **¥17,600** / TPS2026v1 **¥18,600**(社内回収コスト)。一方、見積りテンプレート.xlsx/ツールの **¥17,900**(2026 B8)はお客様向けLabor単価で、用途が異なる(CPSの`見積詳細`にはサンプルとして17,900が入力されており、単価はBand×年度のパラメーターを参照/上書き)。CPSでは「Hourly Recovery Cost」と「提示額ベースLabor単価」を混同しないよう、CPS出力でBand/単価を明示する必要がある。

## 4. 出張費ルール仕様 (出張費アシスタント)

**入力 (手入力=Manual / 既定値=Template / 自動=Tool)**

| 入力 | 取得元 | 備考 |
|---|---|---|
| 基点事業所 (東京都内/名古屋/大阪/幕張) | Manual | `出張判定図.pdf`の4拠点 |
| 距離区分 (短/中/遠) | Manual | 図の色で判定(赤=中、青=遠)。駅名→区分の自動判定は判定表整備まで未実装 |
| 出張形態 (日帰り/宿泊) | Tool(既定)→Manual | 暫定: 遠距離=宿泊、短・中=日帰り。変更可 |
| 人数 | Manual | 自動化しない |
| 現地作業時間 | Tool→Manual | 構築+テスト工数(「移動時間」行を除く)。上書き可 |
| 週あたり稼働時間 | Template(40h) | 例: 200h÷40h=5週 |
| 1回あたり宿泊数 | Template(4泊) | 暫定値(要確認) |
| 往復交通費 / 宿泊費 | Manual / Template(上限10,000) | |
| 食事区分 | Manual | 宿泊出張手当 4,000/3,200/1,300/500円 |

**計算式**

```
宿泊: 基本訪問回数 = ceil(現地h ÷ 週稼働h)    日帰り: 基本訪問回数 = ceil(現地h ÷ 8h)
訪問回数 = ceil(基本訪問回数 × 1.2)                         … 予備20%
宿泊数   = ceil(基本訪問回数 × 1回あたり宿泊数 × 1.2)       … 宿泊時のみ
出張手当 = 宿泊: 食事別手当 × 宿泊数 / 日帰り: 中1,500・遠3,500 × 訪問回数 / 短距離: 0
PC借用費 = 中距離以上は計上必須(単価は手入力)
遠距離工数目安 = 片道移動h × 2 × 訪問回数 × 0.5          … 表示のみ。工数へは自動加算しない
合計 = 交通費×人数×回数 + 宿泊費×人数×泊数 + 手当×人数×回数
```

**未確定(運用ルールとして要確認)**: ①宿泊時に中距離/遠距離手当を併給するか ②距離区分ごとの標準出張形態 ③1回あたり宿泊数の標準 ④短距離でも交通費が必要か ⑤出張判定図('98年版)の現行性。

### 8-2. CPS作成ツール(スライド14〜18)の理解

- 流れ: ①HTML「見積詳細入力ツール」で入力 → ②JSON(`CostPlan_見積詳細_YYYYMMDDhhmmss.json`)ダウンロード → ③作業フォルダへ移動 → ④PowerShell「RunExcel」がマクロ(複数年)を実行し `CostPlan_Output_YYYYMMDD_hhmmss.xlsm` を作成(年をまたぐ場合は サブ/見積詳細 が◯年目に分割)。
