# なぜHTMLツールなのか？ — Storage Quotation System 導入価値と全体設計

本書は、IBM Storage Expert Labs Japan における見積・契約支援業務について、**「なぜ現行Excelから本HTMLツール群（Storage Quotation System）へ切り替えるのか」**、その実務的価値・設計思想・全体データフロー・セキュリティ管理方針をまとめたレビュー用説明資料です。

---

## 1. エグゼクティブ・サマリー

従来のストレージ見積業務では、営業からの依頼受付、工数・出張費の試算、顧客向け概算見積書の作成、S-LINKメタデータ／サービス仕様書・別紙の起票、そして Cost Plan Sheet (CPS) の作成に至るまで、**同じ案件情報を複数ファイルに手作業で転記・再入力**していました。

本HTMLツール群（Storage Quotation System）は、営業が作成した「見積もり依頼記入シート（.xlsx）」を **Single Source of Truth（唯一の信頼できる情報源）** としてブラウザ上で一括読込みし、後続の全工程へシームレスに自動連携します。

        C --> D[③ 顧客提出用資料<br>PDF / Excel .xlsx]

## 2. 現行Excelの課題 vs HTMLツールの改善（価値対比）

| 評価軸 | 現行Excel運用での課題 | HTMLツール（本システム）での改善・価値 |
|---|---|---|
| **転記コスト・手作業** | 依頼書、概算見積Excel、仕様書Word、別紙、CPSの各フォーマットへ、案件名・期間・顧客名・工数・金額を何度もコピペ・手入力。 | **Single Source一括連携**<br>依頼Excelをドラッグ＆ドロップするだけで全項目を自動解析・全ツールへ連動。再入力ゼロへ。 |
| **OS・環境の依存性** | Windows専用マクロ(VBA)に依存。Mac環境ではマクロエラーやレイアウト崩れが発生し、手動コピペを余儀なくされていた。 | **100% OS非依存（Mac / Windows共通動作）**<br>Chrome / Safari / Edge 等の標準ブラウザで同一に動作。Excel for Mac / Windows を問わず正規成果物を生成。 |
| **チェックシートの操作性** | Excel上で作業行の追加・削除、文章改行を行うと、行高の崩れやチェックボックスのズレ・重なりが発生。 | **堅牢なWeb UI操作**<br>「＋」「✕」ボタンによる直感的な行追加・削除、チェックON/OFF、文章の自動折り返し、動的な再計算が崩れず動作。 |
| **交通費・出張手当の計算** | 訪問先ごとの距離区分判定、交通機関の運賃調査、宿泊数・手当・帰着日手当の計算が手作業でミスが起きやすい。 | **出張費アシスタントによる自動計算**<br>主要10地点プリセット（運賃・距離区分・移動手段連動）、5業務日ブロックごとの宿泊手当＋帰着日遠距離手当(¥3,500)、予備20%を自動試算。 |
| **成果物の一貫性** | 各成果物が別個のファイルとして分断され、修正時の反映漏れや金額・条件の不一致が発生。 | **一気通貫パイプライン**<br>概算見積の工数・Other Cost・提示額がそのまま仕様書・別紙およびCPS (.xlsm) の所定セルへ連動。 |
| **顧客提出用出力** | 内部用のメモや計算セルを誤って顧客に見せないよう、手作業で別シートにコピーしてクリーンアップしていた。 | **クリーン出力の自動生成**<br>ボタン一つで内部用バッジ・色・セル番地を排除した「前提シート」「見積もりシート」の2シート構成Excel / PDFを即時生成。 |

## 3. 主要機能と自動計算ロジック

### ① 交通費・出張手当の自動計算（主要10地点プリセット）
主要訪問先を選択すると、確認済みの運賃・距離区分・既定移動手段が自動セットされます（「その他」による自由入力・手入力補正も可能）。

| 訪問先 | 距離区分 | 既定移動手段 | 参考往復運賃 | 宿泊費目安（2名分×1.3 切上げ） |
|---|---|---|---|---|
| **名古屋** | 中距離 | 新幹線 | ¥22,000 | ¥60,000 |
| **京都** | 遠距離 | 新幹線 | ¥28,000 | ¥75,000 |
| **大阪** | 遠距離 | 新幹線 | ¥30,000 | ¥80,000 |
| **広島** | 遠距離 | 新幹線 | ¥39,520 | ¥105,000 |
| **福岡（博多）** | 遠距離 | 飛行機 | ¥60,000 | ¥160,000 |
| **福島** | 中距離 | 新幹線 | ¥18,660 | ¥50,000 |
| **仙台** | 遠距離 | 新幹線 | ¥23,260 | ¥65,000 |
| **盛岡** | 遠距離 | 新幹線 | ¥30,900 | ¥85,000 |
| **青森** | 遠距離 | 新幹線 | ¥35,820 | ¥95,000 |
| **北海道（札幌）** | 遠距離 | 飛行機 | ¥80,000 | ¥210,000 |
| **その他（自由入力）** | 手動選択 | 手動選択 | 手動入力 | 運賃連動または手入力 |

#### 出張手当・帰着日手当の算定ルール
- **日帰り出張**:
  - 短距離: 手当なし（¥0）
  - 中距離: ¥1,500 × 訪問回数 × 人数
  - 遠距離: ¥3,500 × 訪問回数 × 人数
- **宿泊出張（5業務日ブロック制）**:
  - 宿泊出張手当: 食事区分別単価（¥4,000 / ¥3,200 / ¥1,300 / ¥500）× 宿泊数 × 人数
  - **帰着日遠距離手当 (¥3,500)**: 遠距離出張時、5業務日ごとに宿泊出張手当4日分＋長距離出張手当1日分（¥3,500）として自動計算（訪問回数 × 1日 × ¥3,500 × 人数）。
- **予備率 (20%)**:
  - 現地作業時間（h）から算出した基本訪問回数・宿泊数に 20% の予備（切上げ）を自動加算。
- **総移動回数**:
  - 往復回数 × 片道2 × 人数 を自動明示。

## 4. CPS (Cost Plan Sheet) へのデータマッピング

CPS入力ツール (`cps-input.html`) は、概算見積および依頼シートから以下の情報を引き継ぎ、記入済み `.xlsm`（2年版 / 3年版）へ直接書き込みます。

```
【入力元】                             【CPS .xlsm 出力セル】
・依頼シート (お客様名・案件名)  ────> メインシート C3, C4
・概算見積 (サービス期間)        ────> メインシート C5 (開始/終了月)
・概算見積 (承認GP%・Risk Level) ────> メインシート C6, E6
・概算見積 (月別工数)            ────> 見積詳細 TEL内コスト (8+3i行: E〜P列)
・概算見積 (交通費・出張手当)    ────> 見積詳細 Other Cost (85+i行: E〜P列)
・概算見積 (提示額)              ────> メインシート O列 (お客様提示額)
・支払計画 (マイルストーン)      ────> 支払計画シート (期日・金額)
```

## 5. データ保存方式とセキュリティ・GitHub管理方針

| 項目 | 公開リポジトリ (`ibm-el-japan`) | 非公開作業用 (`ibmkevin/work`) | ローカルPC (ブラウザ) |
|---|---|---|---|
| **ソースコード・共通パーサ** | 保管・GitHub Pages公開 | バックアップ | 実行 |
| **テストコード・ドキュメント** | 匿名化して公開 | 案件メモ等 | 実行 |
| **実案件データ・顧客名・金額** | **絶対に入れない (0件)** | 必要時のみPrivate保管 | 一時セッション/保存 |
| **CPS実雛形 (.xlsm)・単価表** | **絶対に入れない** | 非公開管理 | ローカル完結 |
| **アクセス権限** | 社内外（ツール利用） | 承認されたSEのみ（要PAT） | 本人のみ |

> **セキュリティ原則:**
> 1. 個人情報・顧客名・Opportunity No・案件金額は公開リポジトリへコミット・Pushしない（Gitフックおよびコミット前スキャンで徹底）。
> 2. 管理者パスワードは平文を保持せず、Salt付き SHA-256 ハッシュ値のみを照合。
> 3. GitHub Pages からのWeb利用時も、データの解析・計算・Excel生成はすべてクライアント（ブラウザ内メモリ）で完結し、外部サーバーへデータを送信しません。
