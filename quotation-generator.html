算定ルール（出張費アシスタント）

  • 宿泊出張: 訪問回数＝ 現地作業h ÷ 週あたり稼働h（切上げ）＝週数。宿泊数＝訪問回数×1回あたり宿泊数。
  • 日帰り出張: 訪問回数＝ 現地作業h ÷ 8h（切上げ）＝現地作業日数。
  • 訪問回数・宿泊数とも予備20%を加算（切上げ）。
  • 出張手当: 宿泊時＝宿泊出張手当（食事別）×宿泊数。日帰り時＝中距離1,500円／遠距離3,500円×訪問回数。短距離は手当なし。
  • 中距離以上はPC借用費を必ず計上。遠距離は 片道移動時間×2×訪問回数×0.5 を工数に追加する目安として表示（工数は手入力のまま）。
  • 距離区分（出張判定図.pdf：東京都内（基点: 東京駅）／名古屋／大阪／幕張の各事業所）: 赤線上の駅＝中距離、青線上の駅＝遠距離、線の無い範囲＝短距離（日帰り圏）。図の範囲外（仙台・福岡など）は遠距離。判定は人が行い、ツールは自動選択しない。

  • ※ 宿泊時に中距離/遠距離手当を併給するか、距離区分ごとの標準出張形態は未確定のため、運用ルールとして要確認（設計課題）。

🙋 GitHub アカウント登録申請（一般ユーザー）

▼

このツールの「💾 保存 → GitHubへ」「📂 GitHubから開く」機能は、案件ファイル専用の非公開リポジトリ（ibmkevin/storage-quotation-work）に保存します。利用するには、GitHub アカウントを持ち、管理者にこのリポジトリへの招待を依頼する必要があります。顧客情報を含むファイルを公開リポジトリへ置かないでください。

📋 ステップ1 — GitHub アカウントの作成（未作成の場合）

  1. https://github.com/signup にアクセスし、無料アカウントを作成する
  2. メールアドレス・パスワード・ユーザー名を設定し、メール認証を完了する
  3. 作成した GitHub ユーザー名（例: taro-ibm）を控えておく

📩 ステップ2 — 管理者へ招待依頼を送る

以下のボタンから管理者宛てにメールを送信してください。件名・本文は自動で入力されます。GitHub ユーザー名の部分だけ書き換えて送ってください。

🔑 ステップ3 — 招待承認後: Personal Access Token (PAT) の取得

管理者から招待メールが届いたら承認し、その後 PAT を発行してツールで使用します。

  1. GitHub にログインし、右上のアイコン → Settings を開く
  2. 左メニュー最下部 Developer settings → Personal access tokens → Tokens (classic) を開く
  3. Generate new token (classic) をクリック
  4. Note に「Storage Quotation ツール用」などを入力、Expiration は「No expiration」または任意の期間を設定
  5. スコープで repo（最上位のチェックボックス）にチェックを入れる
  6. Generate token をクリック → 表示されたトークン（ghp_...）をコピーして安全な場所に保存する
    ⚠️ このページを離れるとトークンは二度と表示されません

💡 ステップ4 — ツールでの使い方

  1. 「💾 保存 → GitHubへ」または「📂 GitHubから開く」ボタンをクリックする
  2. 担当者名（イニシャル）と取得した PAT を入力する
  3. PAT はセッション中のみ保持され、ブラウザを閉じると削除される（再入力が必要）

🔄 ファイル共同編集フロー

▼
  1. ポータル から「ツールを開く」をクリック（URLコピー不要）
  2. データを入力後、「💾 保存 → GitHubへ」または「☁️ API保存」ボタンをクリック
    ファイル名（例: ABC社_20250901_v1_KS.html）・担当者イニシャル・PAT・変更コメントを入力して保存
  3. 別のメンバーは「📂 GitHubから開く」ボタン → 一覧からファイルを選択して編集継続
  4. ファイルを開くと、前バージョンからの差分が自動表示される（変更内容をすぐ確認可能）
  5. 変更履歴は GitHub コミット履歴（案件ファイル用リポジトリ） で「誰が・いつ・何を変更したか」を確認可能

ファイル命名規則

[案件略称]_[YYYYMMDD]_v[番号]_[担当者イニシャル].html
例: ABC社_20250901_v1_KS.html

🔑 【管理者専用】ユーザー登録・権限管理

▼
⚠️ このセクションは管理者のみに表示されます。ユーザー登録は管理者が GitHub から直接行ってください。一般ユーザーには登録方法を案内しないでください。

📋 一般ユーザーの登録手順（Write 権限）

  1. GitHub の Settings → Collaborators and teams を開く
  2. 「Add people」をクリック
  3. 登録したいメンバーの GitHub ユーザー名またはメールアドレスを入力する
  4. ロールを Write（通常メンバー）に設定する
  5. 「Add [username] to this repository」をクリック → 招待メールが自動送信される
  6. 招待されたメンバーがメール内の承認リンクをクリックするとアクセス可能になる

👑 管理者（Admin）の登録手順

  1. GitHub の Settings → Collaborators and teams を開く
  2. 「Add people」をクリック
  3. 登録したいメンバーの GitHub ユーザー名またはメールアドレスを入力する
  4. ロールを Admin に設定する
  5. 「Add [username] to this repository」をクリック → 招待メールが自動送信される
  6. ツール内管理者パスワードも別途伝達すること（口頭または安全な方法で）
