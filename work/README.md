# Storage Quotation System — 案件作業ファイル

> **注意（v2.5.3〜）**: このリポジトリ（`ibm-el-japan/storage-quotation-system`）は**公開**です。顧客情報を含む案件ファイルは置かないでください。
> 案件ファイルは非公開リポジトリ **`ibmkevin/storage-quotation-work`**（要招待）の `work/` に保存します。ツールの「保存 → GitHubへ」「GitHubから開く」は自動的にそちらを使います。

本フォルダ（`work/`）は、Storage Quotation System（見積もり作成ツール）で作成した案件別の見積もり作業用 HTML ファイルをチームで共有・保管するためのディレクトリです。

---

## 📁 ファイル命名規則

```
[案件略称]_[YYYYMMDD]_v[番号]_[担当者イニシャル].html
```

### 例
- `ABC社_20250901_v1_KS.html` （初版・担当者KS）
- `ABC社_20250902_v2_TN.html` （第2版・担当者TN）
- `XYZ銀行_FlashSystem導入_20250915_v1_YK.html`

---

## 🔄 チーム共同編集ワークフロー

1. **ポータルからツールを開く**
   - [Storage Quotation System ポータル](https://ibm-el-japan.github.io/storage-quotation-system/) をブラウザで開きます。
2. **作業・保存**
   - データを入力後、「💾 保存 → GitHubへ」ボタンをクリックしてダウンロードします。
   - ガイドに従い、この `work/` フォルダへドラッグ＆ドロップしてコミットします。
   - （管理者権限をお持ちの方は「☁️ API保存」ボタンから直接コミットも可能です）
3. **他のメンバーが引き継ぎ・編集**
   - ツール右上の「📂 GitHubから開く」をクリックすると、`work/` 内のファイル一覧が表示されます。
   - 該当ファイルをクリックするとデータが復元されます。
4. **🔍 自動差分比較 (Visual Diff)**
   - ファイルを開くと、**前回保存時からの変更点（基本情報・工数・交通費・チェックシート）が色分けモーダルで自動表示**されます。
5. **変更履歴の確認**
   - 誰が・いつ・何を変更したかは、GitHub のコミット履歴および `WORK_LOG.md` で確認できます。
