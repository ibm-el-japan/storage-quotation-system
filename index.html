📌 システム概要・自動化の流れ

「Expert Labs Storage Inputs and Outputs」の運用モデルに基づき、Storage Sales / Tech Sales による依頼入力から、Expert Labs による見積もり試算、S-LINK 登録用メタデータおよび仕様書・別紙 HTML 出力までの各工程で、手作業や二重入力を完全に排除したデータ連携を実現します。

📋 自動化プロセス・メニュー
1

見積もり依頼記入シート

Storage Sales / Tech Sales

原本 Excel (`Quotation Request Form.xlsx`) を完全準拠・刷新した Web フォーム。12項目の事前確認や対象製品・提供条件を快適に入力し、見積もり生成用データをワンクリックで出力します。

依頼シートを開く →
2

概算見積シート

Expert Labs Storage

依頼シートの入力内容を自動解析・マッピング。GitHub `work/` フォルダと直接連携し、前バージョンとの差分表示、クラウド保存・ロード、お客様提出用見積もり出力を完備しています。

概算見積シートを開く →
3

S-LINK & 仕様書・別紙 生成

S-LINK 登録 & 提案書作成

試算された見積もりデータから、S-LINK 登録用メタデータ（契約金額・GP・Contingency・OO・PPTL/PJTL等）および「仕様書」「別紙」を自動整理し、登録用 HTML / コピー用テキストを一括出力します。

S-LINK・仕様書生成 →

👥 チーム共同編集・変更履歴（work/ フォルダ）の利用フロー

全案件の作業ファイルは専用リポジトリの work/ フォルダにて一元管理されます。ブラウザ上で編集した内容を保存すると、誰が・いつ・何を変更したかが WORK_LOG.md および Git コミット履歴に自動追跡されます。

STEP 1
ワンクリックで起動
本ポータルまたは各ツールリンクをクリックしてブラウザ上で直接開きます。
STEP 2
GitHubからファイル読込
「📂 GitHubから開く」で work/ フォルダの案件作業ファイルを選択して読み込みます。
STEP 3
差分ビューの自動確認
前回保存時からの変更点が色分けモーダルで自動表示され、更新内容を一目で把握できます。
STEP 4
work/ へ保存・履歴記録
「💾 保存 → GitHubへ」または「☁️ API保存」で work/ へ保存。WORK_LOG.md に記録されます。
🐙 GitHub 専用リポジトリ (storage-quotation-system) 📁 案件作業ファイルフォルダ (work/) 📝 変更履歴 (WORK_LOG.md) 📜 コミット履歴一覧
